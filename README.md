# نكسا ويب | NEXA WEB — Front-end Demo

## التشغيل
1. فك الضغط.
2. افتح المجلد في Visual Studio Code.
3. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server.
4. عدّل الروابط والأرقام وبيانات التواصل من `index.html`.

## ملاحظات
- المشروع Front-end فقط ومجهز للعرض والتصوير.
- النموذج لا يرسل طلبًا حقيقيًا؛ يظهر رسالة تجريبية.
- الشعار داخل `assets/nexa-logo.jpg` مأخوذ من الصورة المرفقة، ويمكن استبداله بشعار PNG شفاف عند توفره.


- تمت إعادة تصميم الواجهات بالكامل (نظام ألوان ومسافات موحد، أيقونات SVG، قائمة جوال). النسخة السابقة محفوظة في `backup-original/`.
- تم تعديل جميع الباقات والإضافات لتظهر «حسب الطلب» بدون أسعار ثابتة.

## الإصدار الثاني من التصميم (Aurora Night)
- نظام تصميم جديد بالكامل في `style.css` (متغيرات للألوان والمسافات والظلال والحركة في `:root`).
- الحركات تستخدم **Framer Motion** (نسخة DOM بدون React) المحفوظة محليًا في `assets/vendor/framer-motion-dom.js`،
  ويعمل الموقع بالكامل حتى لو لم تُحمَّل المكتبة، ويحترم إعداد «تقليل الحركة» في الجهاز.
- صفحات الأعمال في `work/` تحتفظ بهوية كل عميل، وتشترك في `work/demo-kit.css` (شريط نكسا السفلي + الحركات)،
  ويُخفى الشريط تلقائيًا عند عرض الصفحة داخل معاينات الصفحة الرئيسية.
- عند تعديل `style.css` أو `script.js` غيّر رقم الإصدار `?v=` في `index.html` حتى يظهر التحديث للزوار فورًا.
